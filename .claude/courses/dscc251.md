# DSCC/LING 251/451: Machine Learning with Limited Data

Primarily Data Science, cross-listed with Linguistics; undergrad/grad cross-listed.

**Most recent offering**: Spring 2026 — `teaching/dscc251/spring26/index.html`

## Meeting

Tuesday and Thursday, 9:40–10:55 AM.

## Grading

- 45% Term project
- 30% Student-led discussions
- 25% Participation

No homework — the course is seminar-style.

## Format

Thursday is an instructor lecture introducing a topic; the following Tuesday is a student-led
discussion on that topic. Two presenters per discussion session, roughly 30–35 minutes each.
Papers must be approved a week ahead and shared with the class by the Friday before. Students
are encouraged to pick papers from their own application domain.

Discussion slots are assigned from ranked student preferences submitted after week 1, rather
than first-come-first-served.

## Topic Sequence

28 sessions.

- Foundations (lecture only, no discussions yet): course framing and data scarcity; supervised
  learning review; generalization and overfitting in low-data regimes; cluster setup and
  discussion format
- Core techniques: unsupervised learning (discrete structure discovery; continuous structure
  discovery), self-supervised learning, semi-supervised learning, active learning, weak
  supervision
- Post-break: transfer learning, domain adaptation, few-shot learning, meta-learning, data
  augmentation and synthetic data, human-in-the-loop ML
- Project presentations

## Term Project

Apply data-efficient ML techniques to an application area of the student's choice. Must pose and
test a falsifiable hypothesis. Individual or small groups of 2–3; the instructor suggests
groupings after M1 based on shared interests, but formation is up to students.

Milestones follow the standard sequence in `conventions.md`, including M5 and the code
walkthrough appointments specific to this course. Writeup uses ACL format.
